# 💼 Portfólio Pessoal

Este é um repositório que criei para hospedar e explicar o código do meu projeto de portfólio pessoal!  
Nele conto detalhes e documento como fiz o código de todo o projeto.

---

## ✨ Funcionalidades e Diferenciais

- **Design responsivo:**  
  Fiz o meu melhor para garantir que o site funcionasse em grande parte dos dispositivos, desde smartphones em resoluções baixas — até extremas como QVGA (320×240) — a tablets, notebooks, computadores de mesa com monitores variados e televisores.

- **Organização de código:**  
  Garanti que o código estivesse seguindo as boas práticas e o padrão de indentação, além de comentários explicativos em cada parte e função (pessoalmente me ajudam muito a me localizar no meio de tantas linhas).

- **Lógica JavaScript customizada:**  
  Usei uma lógica personalizada para o site, como no exemplo do loader inicial, e também utilizei bibliotecas como o `wow.js` para o JavaScript do site, garantindo animações.

- **Integração com API:**  
  No site, adicionei a API do **Formspree** para facilitar o contato entre possíveis interessados por meio de envio automatizado de e-mails.

- **Pronto para expansão:**  
  Estruturei o código pensando em futuras adições, como por exemplo na área de experiências com novos projetos e na parte dos cards de experiências conforme maiores formações pessoais.

- **Controle de versão com Git:**  
  Durante todo o projeto utilizei o **Git** para fazer uploads na minha conta pessoal do **GitHub** e ajudar no versionamento.
